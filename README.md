
 # 8-Bit ALU Hardware Project

Project Description

The 8-Bit Arithmetic Logic Unit (ALU) is a digital hardware circuit designed to perform arithmetic and logical operations on 8-bit binary inputs. The project is implemented using breadboards, logic ICs, registers, LEDs, switches, and connecting wires.


Hardware Components

- Breadboard
- A-Register (8-bit)
- B-Register (8-bit)
- Arithmetic Logic Unit (ALU)
- AND Logic Circuit
- OR Logic Circuit
- Control Unit
- Bus System
- Clock Circuit
- Logic ICs
- LEDs and resistors
- Push buttons and switches
- Connecting wires
- Power supply

Main Functional Blocks

1. A-Register: Stores the first 8-bit input.
2. B-Register: Stores the second 8-bit input.
3. ALU: Performs arithmetic and logical operations.
4. AND Logic: Performs bitwise AND operations.
5. OR Logic: Performs bitwise OR operations.
6. Bus System: Transfers data between circuit components.
7. Control Unit: Selects and controls the required operation.
8. Clock Circuit: Provides timing signals for register operations.
9. LED Indicators: Display circuit status and output signals.

Working Principle

1. Enter the first 8-bit binary value into the A-Register.
2. Enter the second 8-bit binary value into the B-Register.
3. Select the required operation using the control circuit.
4. The ALU processes the inputs according to the selected operation.
5. The result is transferred through the bus system.
6. LEDs indicate the output and relevant control signals.

Project Objective

To design and demonstrate an 8-bit ALU that integrates registers, logic circuits, a bus system, and control signals to perform digital operations.
